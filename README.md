# Theo Egginton

I run operations for a living and build the tools I need to do it. General Manager at Chillhop Music, based in Sheffield.

Most of what's here came out of one problem. I wanted several AI agents to work on the same knowledge base for months without losing context, overwriting each other or acting without permission.

## Projects

**[New Ocean OS](https://github.com/parkbenchepiphany/new-ocean-os)**
A desktop app that sits on top of an Obsidian vault. Notes stay as plain markdown files on disk. It adds search, a home dashboard and a rich editor that refuses to save anything it can't reproduce byte for byte. Tauri, React and TypeScript.

**[New Ocean Agent OS](https://github.com/parkbenchepiphany/new-ocean-agent-os)**
Rules for several AI agents sharing one knowledge base. Each agent gets folders it can read, write or only append to. Every attempted write is checked and logged, including the ones that get refused. Python.

**[Agent Approval Gateway](https://github.com/parkbenchepiphany/agent-approval-gateway)**
Agents propose actions and a person approves them before anything runs. Python.

## How I use it

These aren't demos. My own setup runs on the same ideas every day. It's a vault of about 2,500 notes, several agents that each have a written charter and a lane, and a daily job that files whatever came in overnight.

## What I've learned so far

- Keep knowledge in files a person can read.
- Write permissions down.
- Log refusals as well as actions.
- A person approves anything that matters.
